# Староста — PWA для посещаемости группы

Ультра-минималистичное монохромное веб-приложение для старосты университетской группы. Полностью офлайн (localStorage + Service Worker), устанавливается на главный экран iOS/Android.

## Возможности

- **База студентов**: CRUD, подгруппы А/Б, языковые треки, массовый импорт списком
- **Профиль**: аватар и баннер (автосжатие до 150×150 JPEG через Canvas → экономия localStorage)
- **Дизайн-студия**: монохромные палитры + скругления через CSS-переменные, сохранение своих тем
- **Расписание**: Пн–Сб, у каждой пары целевая аудитория (вся группа / А / Б / трек)
- **Журнал посещаемости**: фильтрация по аудитории пары, статусы ✓/✗/🤒, «Все на месте»
- **AI-помощник**: текст + голос (Web Speech API), fuzzy-поиск имён (Левенштейн), Confirm Card
- **Аналитика**: график за 7 дней на чистом CSS, группа риска (>30% пропусков или ≥3 прогулов), доска почёта с медалями
- **Задачи**: объявления, ДЗ, дедлайны с чеклистом
- **Excel (SheetJS)**: импорт базы из .xlsx, экспорт недельного отчёта

## Запуск

Нужен любой статический сервер (Service Worker не работает с `file://`):

```powershell
# Python
python -m http.server 8000

# или Node
npx serve .
```

Открыть http://localhost:8000 — приложение работает и офлайн после первой загрузки.

## Установка на телефон

- **Android/Chrome**: меню ⋮ → «Установить приложение»
- **iOS/Safari**: Поделиться → «На экран „Домой“»

## Структура

```
index.html          — каркас и навигация
manifest.webmanifest, sw.js — PWA
css/style.css       — монохромная тема на CSS-переменных
js/                 — модули приложения (классические скрипты, без сборки)
vendor/xlsx.full.min.js — SheetJS 0.18.5 (локально, офлайн)
icons/              — иконки 192/512/maskable/apple-touch
```

## Данные

Хранятся только в `localStorage` браузера устройства. Очистка данных сайта = полный сброс.
